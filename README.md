# VYNARA

### AI • Data Science • Innovation

VYNARA is the personal portfolio website of **C L Vinaya**, a Computer Science and Engineering (Data Science) student passionate about Artificial Intelligence, Cybersecurity, Data Analytics, Software Engineering, Robotics, and Innovation.
